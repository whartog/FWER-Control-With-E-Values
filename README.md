# FWER-Control-With-E-Values

This repository contains three files, which reproduce the figures from three sections of the paper:

- unif_e_holm_final.py: figures from Section 4.2
- e_Holm_dag_final.py: figures and numerical results from Section 7
- new_yorker_e_values_final.py: figures and numerical results from Section 8

All files set fixed random seeds before they generate any random data. The data for
the New Yorker caption contest is loaded from a URL, but we also include the caption_data.csv
in the repo.
